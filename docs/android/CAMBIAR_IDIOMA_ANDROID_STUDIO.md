# 🌐 Cambiar el Idioma de Android Studio a Español

## 🎯 Método 1: Desde la Configuración de Android Studio (Recomendado)

### Paso 1: Abrir la Configuración

1. **Abrir Settings/Preferences**
   - **Windows/Linux:** **File** → **Settings**
   - **macOS:** **Android Studio** → **Preferences**
   - O presiona: `Ctrl + Alt + S` (Windows/Linux) o `Cmd + ,` (macOS)

### Paso 2: Buscar la Configuración de Idioma

1. **Navegar a la Configuración de Plugins**
   - En el panel izquierdo, busca **"Plugins"**
   - O en la barra de búsqueda superior, escribe: `plugins`

2. **Buscar el Plugin de Idioma**
   - En la pestaña **"Marketplace"**, busca: `Spanish Language Pack`
   - O en la pestaña **"Installed"**, busca plugins de idioma

### Paso 3: Instalar el Plugin de Idioma Español

1. **Instalar el Plugin**
   - Busca **"Spanish Language Pack"** o **"Spanish Language Pack / Español"**
   - Haz clic en **"Install"**
   - Espera a que se instale

2. **Reiniciar Android Studio**
   - Android Studio te pedirá reiniciar
   - Haz clic en **"Restart"** o **"Restart IDE"**

### Paso 4: Verificar el Cambio

1. **Después de Reiniciar**
   - La interfaz debería estar en español
   - Verifica que los menús y opciones aparecen en español

---

## 🎯 Método 2: Instalar el Plugin Manualmente

### Paso 1: Descargar el Plugin

1. **Abrir la Página del Plugin**
   - Ve a: https://plugins.jetbrains.com/plugin/13710-spanish-language-pack---espa-ol
   - O busca "Spanish Language Pack" en el marketplace de JetBrains

2. **Descargar el Plugin**
   - Haz clic en **"Download"**
   - Guarda el archivo `.zip` del plugin

### Paso 2: Instalar desde Archivo

1. **Abrir Settings/Preferences**
   - **File** → **Settings** (Windows/Linux)
   - **Android Studio** → **Preferences** (macOS)
   - O `Ctrl + Alt + S` / `Cmd + ,`

2. **Instalar desde Disco**
   - Ve a **"Plugins"**
   - Haz clic en el icono de **⚙️ (Settings)** en la parte superior
   - Selecciona **"Install Plugin from Disk..."**
   - Selecciona el archivo `.zip` descargado
   - Haz clic en **"OK"**

3. **Reiniciar Android Studio**
   - Android Studio te pedirá reiniciar
   - Haz clic en **"Restart"**

## 🎯 Método 3: Cambiar el Idioma del Sistema (Alternativa)

### Para macOS

1. **Cambiar el Idioma del Sistema**
   - **System Preferences** → **Language & Region**
   - Agrega **Español** como idioma principal
   - Reinicia el Mac

2. **Android Studio Usará el Idioma del Sistema**
   - Android Studio detectará el idioma del sistema
   - La interfaz cambiará a español automáticamente

### Para Windows

1. **Cambiar el Idioma del Sistema**
   - **Settings** → **Time & Language** → **Language**
   - Agrega **Español** como idioma principal
   - Reinicia Windows

2. **Android Studio Usará el Idioma del Sistema**
   - Android Studio detectará el idioma del sistema
   - La interfaz cambiará a español automáticamente

### Para Linux

1. **Cambiar el Idioma del Sistema**
   - Depende de la distribución
   - Generalmente en **System Settings** → **Language**
   - Agrega **Español** como idioma principal
   - Reinicia el sistema

2. **Android Studio Usará el Idioma del Sistema**
   - Android Studio detectará el idioma del sistema
   - La interfaz cambiará a español automáticamente

## ⚠️ Notas Importantes

### Limitaciones del Plugin de Idioma

- **No todas las partes están traducidas:** Algunas partes de Android Studio pueden seguir en inglés
- **Plugins de terceros:** Los plugins de terceros pueden no estar traducidos
- **Mensajes del sistema:** Algunos mensajes del sistema pueden seguir en inglés

### Compatibilidad

- **Versiones de Android Studio:** El plugin de idioma funciona en versiones recientes de Android Studio
- **Actualizaciones:** El plugin se actualiza automáticamente cuando actualizas Android Studio
- **Rendimiento:** El cambio de idioma no afecta el rendimiento de Android Studio

### Volver al Inglés

Si quieres volver al inglés:

1. **Desinstalar el Plugin**
   - **File** → **Settings** → **Plugins**
   - Busca **"Spanish Language Pack"**
   - Haz clic en **"Uninstall"**
   - Reinicia Android Studio

2. **O Cambiar el Idioma del Plugin**
   - En la configuración del plugin, puedes cambiar el idioma
   - O desactivar el plugin temporalmente

## 🐛 Solución de Problemas

### Problema 1: "No se encuentra el plugin de idioma"

**Solución:**
1. Verifica que tienes conexión a internet
2. Busca en el marketplace: `Spanish Language Pack`
3. Si no aparece, intenta instalar manualmente desde el archivo

### Problema 2: "El plugin no cambia el idioma"

**Solución:**
1. Verifica que el plugin está instalado y activado
2. Reinicia Android Studio completamente
3. Verifica que el plugin está en la lista de plugins instalados

### Problema 3: "Algunas partes siguen en inglés"

**Solución:**
1. Esto es normal, no todas las partes están traducidas
2. El plugin se actualiza regularmente con más traducciones
3. Puedes reportar partes no traducidas al desarrollador del plugin

### Problema 4: "El plugin causa problemas"

**Solución:**
1. Desinstala el plugin temporalmente
2. Reinicia Android Studio
3. Si el problema persiste, reporta el problema al desarrollador
